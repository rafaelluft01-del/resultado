# /resultado: o Claude te entrevista antes de começar

**Criada por Rafael Luft · [@rafaelluft.ia](https://www.instagram.com/rafaelluft.ia/)**

Uma skill para o Claude Code. Antes de fazer qualquer coisa grande, o Claude pede para você descrever o resultado que quer (escrevendo ou por áudio), pergunta só o que faltou, escreve um briefing de uma página e só começa quando você aprova. Você nunca precisa explicar como fazer.

## Como instalar

1. Baixe o arquivo [`resultado-skill.md`](resultado-skill.md) (abra e clique no ícone de download, no canto direito).
2. Abra o app do Claude para desktop ([claude.ai/download](https://claude.ai/download)) e clique na aba **Code**.
3. Arraste o arquivo para o chat e escreva: **instala**.
4. Abra uma conversa nova e teste: `/resultado uma planilha para controlar meus gastos do mês`

Precisa do Claude Code, que vem nos planos pagos do Claude. A skill é só um arquivo de texto: não instala programa, não acessa a internet e não guarda nada seu.

## Como ela funciona

1. **Ouve:** pede para você descrever o resultado com o máximo de detalhes.
2. **Lê:** usa a sua descrição e os arquivos ou exemplos que você mostrou.
3. **Pergunta:** só o que faltou, até 3 perguntas por vez, com opções.
4. **Escreve:** um briefing de uma página sobre o resultado.
5. **Espera:** nada começa antes do seu sim.

A ideia de perguntar sobre o resultado veio de um post do [@champmack](https://www.instagram.com/champmack/). O texto da skill é de Rafael Luft ([@rafaelluft.ia](https://www.instagram.com/rafaelluft.ia/)), em português.
